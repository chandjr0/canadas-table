# Sysco Canada — Marketing Website

A multi-page marketing site for Sysco Canada foodservice distribution, built with TanStack Start, React, TypeScript, and Tailwind CSS.

## Development

Requires [Bun](https://bun.sh) or Node.js 20+.

```sh
bun install
bun run dev
```

## Build

```sh
bun run build
bun run preview
```

Set `VITE_SITE_URL` to your production domain before building so canonical URLs and the sitemap use the correct base URL.

## Stack

- TanStack Start & React Router
- TypeScript
- Tailwind CSS v4
- shadcn/ui component library
